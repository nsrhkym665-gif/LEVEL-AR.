# ROCK NEWS AR V3 — Gaming Hub

نسخة Static تعمل على GitHub Pages بدون Backend.

## ما الموجود؟
- أخبار متعددة الشركات مع المصدر الأصلي.
- قاعدة بيانات 200 لعبة.
- صفحات لعبة داخل Modal.
- PlayStation / Xbox / Nintendo / PC / Mobile.
- فيديوهات YouTube تعمل داخل الموقع عبر iframe الرسمي.
- متطلبات تشغيل/أداة فحص جهاز إرشادية.
- مواعيد إصدار.
- مفضلة عبر localStorage.
- بحث وفلاتر.
- PWA + Service Worker.
- Responsive RTL.

## النشر
ارفع الملفات كما هي إلى نفس GitHub Repository الذي تستخدمه. لا تحتاج إلى حذف الموقع.

## مهم
الصور الحالية داخل الكروت هي Artwork مولد داخل CSS وليست صورًا منسوخة من الشركات. يمكن لاحقًا ربط كل لعبة بصورة رسمية/مرخصة عند توفر مصدر مناسب.

الأخبار الحالية المعروضة في data/data.js مختارة من صفحات رسمية/مصادر أصلية تم التحقق منها وقت بناء النسخة.
